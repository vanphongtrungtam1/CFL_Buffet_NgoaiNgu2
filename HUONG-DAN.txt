QUAN TRỌNG
- Upload toàn bộ file ngang hàng ở thư mục gốc (root) của repository.
- Không tạo thư mục con và không đổi tên file.

CÁCH TẠO TRANG GITHUB PAGES MỚI
1. Tạo một repository mới trên GitHub.
2. Chọn Add file > Upload files.
3. Kéo thả cả 4 file vào cùng một cấp.
4. Commit changes.
5. Vào Settings > Pages.
6. Ở Build and deployment, chọn Source: Deploy from a branch.
7. Chọn Branch: main và Folder: /(root), sau đó Save.
8. Chờ GitHub Pages xuất bản trang.
